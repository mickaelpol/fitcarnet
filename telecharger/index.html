Sur Android

Telecharger l'application Ou l'utiliser dans le navigateur
  1. Appuie sur Telecharger. Android previent que ce type de fichier peut etre dangereux : c'est le message normal pour toute application installee hors du Play Store. Conserver.
  2. Ouvre le fichier telecharge. Android demande d'autoriser l'installation depuis cette source — il parle de ton navigateur, pas de l'application. Accepte, puis reviens en arriere.
  3. Appuie sur Installer.

Les mises a jour se font toutes seules. L'application recupere les nouveautes au demarrage suivant, sans rien demander.

Quelques fois par an, une mise a jour touche au coeur de l'application et demande une nouvelle installation. Ce jour-la, un bandeau apparait dans l'onglet Compte avec un bouton. Android impose cet appui, aucune application ne peut en installer une autre sans lui.

Sur iPhone

Pas d'application a installer. Ouvre carnet.mickael-pol.fr dans Safari, puis Partager → Sur l'ecran d'accueil : elle s'ouvre en plein ecran, comme une application.
